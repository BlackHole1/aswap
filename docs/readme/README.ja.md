# aswap

[English](../../README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | 日本語 | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md) | [Español](README.es.md)

Claude Code のアカウント切り替えツール：[claude-swap](https://github.com/realiti4/claude-swap) (`cswap`) に、継続的にメンテナンスされる修正を重ねたものです。

`cswap` は複数の Claude アカウントを切り替え、各アカウントの利用枠を追跡し、最も余裕のあるアカウントへ移してくれます。aswap が提供するのは同じツールです。無修正の上流ソースからビルドし、上流がまだ直していない問題に対する小さく審査しやすいパッチ群を重ねています。手に入るのは使い慣れた `cswap` コマンドそのもの、ただし角が取れた状態です。

## 名前について

aswap は **account swap** (アカウントの切り替え) の略で、このツールがすることそのものです。`cswap` と並べてみると、`a` はこのプロジェクトが加える唯一のものでもあります。aswap は cswap にパッチ群を足したもので、それ以上ではありません。そして Claude Code が汎用のエージェント実行環境へ育つにつれ、`a` にはそれに伴うアカウント、AI アカウントやエージェントアカウントの居場所も残されています。

## インストール

```bash
uv tool install aswap      # または: pipx install aswap
aswap --version
```

`aswap` は `cswap` のすべての使い方を受け付け、上流の `cswap` と並んでインストールされ、それには触れません。`cswap` という名前でも aswap を実行したい場合：

```bash
aswap link                 # aswap の隣に cswap ランチャーを作成。aswap unlink で削除
```

`aswap link` は自分が作ったものでない `cswap` を上書きしません。先に上流をアンインストールする (`uv tool uninstall claude-swap`) か、`--force` を付けてください。

## アップグレード

```bash
aswap upgrade              # インストール方法に応じて uv tool upgrade aswap または pipx upgrade aswap
```

ソースからのビルドと、PyPI の `cswap` をパッチ適用版でその場で置き換える方法は [CONTRIBUTING.md](../../CONTRIBUTING.md) にあります。

各パッチは 1 コミットで、コミットメッセージが上流の問題を説明しています。全一覧は [patches/.patches](../../patches/.patches) にあります。

## 作り方

上流は fork しません。`cswap/` に git submodule としてそのまま取り込み、すべての変更は通常の `git am` パッチとして `patches/` に置き、`patches/.patches` に列挙された順に適用します。これは [Electron が Node と Chromium のパッチを管理している方式](https://github.com/electron/electron/tree/main/patches) と同じです。差分は小さく読みやすいまま、上流の更新は merge ではなくパッチ列の rebase になります。詳細、コマンド、パッチのワークフローは [CONTRIBUTING.md](../../CONTRIBUTING.md) にあります。
